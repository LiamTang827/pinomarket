# 基础协议：两笔订单与 AI 节点比例实验

## 本轮问题

协议规则保持不变。Alice 先发送一笔加密买单，Bob 观察到公开密文元数据后独立决定自己的买单。我们检查：改变 AI 决策节点的比例，会怎样影响承诺、共同登记、两笔订单的相对顺序和最终处理。

本轮只有两笔订单，不引入孔多塞循环，也不加入新的排序、收费、押金或惩罚机制。此前被撤回的排序扩展结果不作为本轮输入或对照。

## 网络与角色

网络使用 8 个本机独立节点进程、现有 CometBFT 共识和门限密码实现。参数为 f=2、收录与名单门槛 q=6、解密门槛 t=3；每节点本轮容量为 4，服务前缀最多处理 2 笔。

|分配给模型决策的比例|模型节点数|固定诚实规则节点数|与 f=2 的关系|
|---|---:|---:|---|
|0%|0|8|诚实节点对照|
|25%|2|6|容错范围内|
|50%|4|4|超范围压力测试|
|100%|8|0|超范围压力测试|

“模型节点”表示获得了受限决策能力，并不等于每次都会撒谎。模型允许选择正常动作。角色分配使用固定种子；各节点保持独立观察与历史，Bob 无法控制它们。模型的对抗测试目标不代表真实节点的经济动机。

50% 和 100% 仍只覆盖开放给模型的应用层动作。模型不能改写程序、共识投票或秘密份额，不能据此宣称覆盖了完整的恶意共识攻击。

## 模型看什么、能做什么

- 节点只看自己的协议阶段、高度、轮次、额度、公开密文元数据、已接单记录与锁定后的服务名单。
- 交易方在节点模型输入中使用匿名标识，不提供信息领先者、攻击者标签或其他节点的历史。
- 不提供交易明文、对称密钥和秘密解密份额；模型没有 shell、文件、节点控制或私聊工具。
- 接单可选正常、拒收、额外延迟 0–1500ms；准备名单可选全部包含或明确保留自己的部分订单 ID；解密可选正常发布自己的份额或扣留。
- 节点之间仍有正常协议传播与共识通信；禁止的是 agent 交换策略、共享模型对话或接受 Bob 指令。

每个模型节点在一组运行中最多调用模型 6 次，Bob 最多 1 次。模型在真实观察到达后选择动作，不预置“必须漏掉 Alice”的答案。模型返回的短解释仅是自述，不是完整内部思考。

Alice 请求买 4 份；市场有 10 份固定价库存，每份 60 分。Bob 用自己的 1000 分余额选择买 1–10 份及额外等待 0–1000ms，无法看到 Alice 的隐藏数量。成交份额用于观察资源分配，不作为金融利润或真实三明治收益。

## 相对顺序能说明多少

现有批内规则按公开 owner、nonce、密文 ID 给出确定性执行顺序；轮间追加队列，服务前缀先锁定再解密。模型没有改变排序规则的工具。

因此，使用本轮的 `alice`、`bob` 钱包时，只要两笔都进入同一轮登记，现有比较规则就把 Alice 放在 Bob 前面。这个结果不能证明先发送者在任意身份和网络中都能优先执行。

本轮分别记录：两笔都登记且 Alice 在前、两笔都登记且 Bob 在前、仅 Alice 登记、仅 Bob 登记、两笔都未登记。缺失订单的相对顺序记为未定义，不记作顺序反转。再检查实际执行是否遵守已经锁定的顺序。

## 等待、对照与停止条件

实验对每个节点的提交加入固定种子的 0–70ms 传输抖动。Alice 开始发送后才触发 Bob 的模型决定，因此实际发送间隔还包含模型调用时间；结果记录实际间隔。

在线组使用 120 区块接单窗口，在关闭前 60 区块启动名单准备，观察上限为 125 秒。窗口放大用于容纳模型调用，不代表生产部署延迟。提前准备之后的新接单正常加入名单。

非零模型比例组另跑诚实等待对照：复用 Bob 的决定和已记录的回调等待，但把节点动作换成正常处理。回放扣除已经等过的排队时间。独立网络的共识调度不同，不能称为完全相同的执行轨迹。

记录停止时所处阶段：未完成共同登记、登记完成但 Alice 缺失、已锁序等待份额、已登记尚未处理，或 Alice 已处理。到时限仍未完成的样本保留，不丢弃。

## 如何核对

实际承诺签名、提交并被选中的名单、已提交的解密份额和终点状态用于确认动作效果。单凭模型选择“漏报”或“扣留”，不能断言攻击已经生效。

模型超时、非法动作、回调失败或节点异常退出与主动拒收分别记录；前者影响实验有效性，不能算作协议攻击成功。终点快照与稍后审计可能处于不同高度，停滞判断以终点快照为准。

CPU/RSS 是本机节点进程的抽样；HTTP 请求体字节不含全网传播、共识和模型流量。本轮每比例一个预定样本；50% 因一次接口失败额外完整补跑一次，原记录保留。不能据此估计攻击成功率或吞吐上限。

## 运行与材料

```sh
./scripts/go.sh build -o bin/pinocchio ./cmd/pinocchio
.venv/bin/python harness/base_pair_experiment.py \
  --binary "$PWD/bin/pinocchio" --state-dir "$PWD/.local/chatgpt" \
  --out "$PWD/runs/base-pair-new" --fractions 0,25,50,100 \
  --window-blocks 120 --prepare-blocks 60 --deadline 125
```

使用已保存的连接；在线运行会消耗模型额度，输出目录须不存在。原始 `network/` 含演示私钥，保存在 Git 忽略的 `runs/` 下。
