# 实验范围纠正

日期：2026-10-23。

## 错误与撤回

用户要求参考 AOAB 的实验方法。助手未经要求把中位数排序、签名接单序号和“观察不足后置”规则加入了项目，并据此开展实验。这超出了项目范围。

此前关于“两节点漏报导致 Alice 观察数不足而后置”的解释只适用于该错误扩展，不能据此判定用户基础协议有这一漏洞，也不能作为本项目的保护效果、性能或原创性结论。相关报告已撤回。

## 已纠正的范围

- 移除中位数计算、排序资格阈值、观察不足后置和对应排序元数据。
- 移除节点虚报序号工具、相关专用测试和对比实验脚本。
- 基础登记继续使用有效完整名单的符合条件并集；每笔单的名单出现次数不决定其排序资格或优先级。
- 批内恢复原有公开 owner、nonce、密文 ID 的确定性执行占位顺序；轮间队列与锁序后解密保留。占位顺序不宣称到达时间公平性。
- 保留门限加密、收录承诺、名单、登记、服务前缀锁定、执行、漏报证据与独立 agent 接口。
- 旧扩展配置会被拒绝，旧扩展轨迹不能自动用于基础协议的等待回放。
